# Локален уеб app — план за изпълнение

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Локален уеб app (`web/`), който прави каквото Android app-ът, през същия relay и LAN път, с пълна клавиатура.

**Architecture:** Node сървър на `127.0.0.1` е клиентът към relay-а и LAN-а (порт на `RelayClient`, `LanSession`, `TerminalStreamGate`); браузърът е само екран с xterm.js и говори с Node по локален WebSocket.

**Tech Stack:** Node 24 (ESM, `node --test`), `ws` 8, `@xterm/xterm` 5.5.0, чист HTML/CSS/JS в браузъра.

**Spec:** [2026-11-10-web-app-design.md](2026-11-10-web-app-design.md)

## Global Constraints

- Нищо в `app/` не се пипа. `tools/mock-host.mjs` — само добавки.
- Без адрес на relay и ключове в repo-то; примерният relay е `relay.example.com`.
- UI текст, коментари и имена на тестове — на български; имена в кода — на английски от `docs/CONTEXT.md`.
- Сървърът слуша само на `127.0.0.1`, порт `8790` (`PORT`). Конфигурация: `~/.config/supacode-remote-web/config.json` (0600), папката от `SUPACODE_REMOTE_WEB_CONFIG_DIR` в тестовете.
- Протоколът v1 + `tab.new` с `cols`/`rows` (ОП27). Никакъв `resize`.
- `ATTACH_SCROLLBACK = 500`, ping 30 s, тишина 75 s, пауза 1→30 s, LAN timeout 2,5 s, LAN нов опит 10 s→300 s, `list` на 3 s, `tab.new` чака 12 s, `sendLine` пауза 150 ms.
- Commit само по път, на `captain/20261110-web`; преди commit `./build-project.sh` с лог.

## Review Focus

1. xterm.js отговаря на DA/CPR → двоен отговор в PTY-то. Тест: в браузъра `printf '\033[c\033[6n'` не дава `input` в лога на mock-а (Task 7, ръчна проба).
2. Чужд сертификат на LAN адреса → ключът не бива да тръгне. Тест в Task 3.
3. Втори таб на браузъра → двата не бива да си крадат `attach` тихо. Тест в Task 6.
4. Mac-ът изчезва и се връща (`mock-offline`) или LAN пада → терминалът се закача наново сам. Тест в Task 5.
5. Нов `list` с непознат `status` / `kind` / `activity` → не чупи списъка. Тест в Task 2 и Task 4.
