# Supacode Remote — задачи

## 1. Отворени

- **ТР1. Писане направо в терминала.** Решено с „Живи клавиши“ (ПР5): собствено поле с
  `InputConnection` вместо xterm.js onData. Остава да се провери на телефона с
  истинския Gboard и български.
- **ТР2. Pinch zoom на истинския телефон.** Zoom-ът на страницата е включен, но `adb` не
  може да направи жест с два пръста — да се провери на телефона.
- **ТР3. Стрелки в application cursor режим.** Стрелките са `ESC [ A` по протокола.
  Програма, включила DECCKM, чака `ESC O A`; повечето приемат и двете.

- **ТР4. Известия след рестарт на процеса.** Ако Android убие процеса и го пусне пак
  (START_STICKY), първият `list` дава известие за всички табове, които вече чакат.

- **ТР5. „Живи клавиши“ и завъртане.** Скрита с Back клавиатура се отваря сама след завъртане:
  всяко ново `LiveKeysView` вика `showKeyboard()`. Да се отваря само при изрично действие
  (флаг, който оцелява завъртането). От преди лентите на терминала (ЦЕ1 F2).
- **ТР6. UI тестове за лентите на терминала.** Фокус, клавиатура, Back и запазения текст се
  проверяват само в emulator-а; няма `androidTest`. Compose UI тест за тях (ЦЕ1 F4).

- **УА1. Уеб app: избор на Mac (multi-host).** Шевовете са готови (`clientUrl(base, hostId)`,
  `hosts` / `boundHost` в `state`, `selectedHostId` в `config.json`). Остава списъкът „Mac-ове“ в
  страницата и правилото ОП20, щом relay-ят с `hosts` е deploy-нат.
- **УА2. Уеб app: известие „агент чака“.** Браузърът може да показва Notification при преход към
  `awaitingInput`; сега броят чакащи е само в заглавието на таба.
- **УА3. Уеб app: проба срещу истински Mac.** Досега само срещу mock-а: relay с истинския ключ,
  LAN пътят, Claude Code с мишка и скрол, paste с bracketed paste, маркиране с ⌥.

## 2. Проверки на телефона

- **ПТ1.** Setup с истинския relay и клиентския ключ от `~/.config/supacode/remote-client-key.txt`.
- **ПТ2.** Таб с Claude Code: `!pwd`, `/btw`, „Предложи“ пълни полето.
- **ПТ3.** Размерът на терминала на Mac-а не се сменя, докато се пише от телефона.
- **ПТ4.** „Известия, когато агент чака“: телефонът заключен 30+ минути, агент чака вход —
  известието идва, а докосването отваря терминала.
- **ПТ5.** „Живи клавиши“ с Gboard на български: дума с автокорекция не се удвоява.
